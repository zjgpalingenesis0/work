# 442. 数组中重复的数据

- LeetCode：[442. 数组中重复的数据](https://leetcode.cn/problems/find-all-duplicates-in-an-array/)
- 难度：中等

## 先理解题意

数组长度为 `n`，其中每个数字都处于 `1` 到 `n` 之间。每个数字最多出现两次，需要返回所有出现两次的数字。

例如：

```text
nums = [4, 3, 2, 7, 8, 2, 3, 1]
```

其中：

```text
2 出现两次
3 出现两次
```

所以返回：

```text
[2, 3]
```

## 方法一：使用 `Set`

### 解题思路

遍历数组时，使用 `Set` 保存已经见过的数字：

- 当前数字不在 `Set` 中：把它加入 `Set`。
- 当前数字已经在 `Set` 中：说明它是重复数字，加入结果。

### 用到的数据结构及原因

#### `Set`（哈希集合）

保存已经出现过的数字。

选择 `Set` 的原因：

1. 可以平均 `O(1)` 判断一个数字是否出现过。
2. 逻辑直观，适合作为第一种思路。

### JavaScript 代码

```js
/**
 * @param {number[]} nums
 * @return {number[]}
 */
var findDuplicates = function (nums) {
  const seen = new Set();
  const result = [];

  for (const number of nums) {
    if (seen.has(number)) {
      result.push(number);
    } else {
      seen.add(number);
    }
  }

  return result;
};
```

### 复杂度分析

- 时间复杂度：`O(n)`。
- 空间复杂度：`O(n)`，因为 `Set` 最坏需要保存所有不同数字。

## 方法二：原地正负标记

### 为什么可以原地标记

题目给了一个非常重要的条件：

```text
数组长度为 n
每个数字都在 1 到 n 之间
```

因此每个数字都可以对应到数组中的一个合法下标：

```text
数字 1 -> 下标 0
数字 2 -> 下标 1
数字 3 -> 下标 2
...
数字 n -> 下标 n - 1
```

转换公式是：

```text
index = number - 1
```

可以利用对应位置数字的正负号，记录某个数字是否已经出现过。

### 标记规则

遍历到数字 `number` 时，找到它对应的位置：

```text
index = abs(number) - 1
```

然后检查 `nums[index]`：

- 如果是正数：第一次见到 `number`，将 `nums[index]` 变成负数作为标记。
- 如果已经是负数：之前已经见过 `number`，所以它是重复数字。

这里数组元素的绝对值仍然保存原数字，正负号只负责表示“是否访问过”。

## 用到的数据结构及原因

### 原数组 `nums`

直接使用原数组每个位置的正负号充当访问标记，不创建额外 `Set` 或计数数组。

选择这种方式的原因：

1. 数值范围恰好可以映射到数组下标。
2. 只改变正负号，不会丢失数字的绝对值。
3. 可以把额外空间复杂度降到 `O(1)`。

### 结果数组 `result`

保存所有发现的重复数字。返回结果所需空间通常不计入额外空间复杂度。

## 用到的方法及原因

### 下标映射

因为数字从 `1` 开始、数组下标从 `0` 开始，所以使用：

```text
index = number - 1
```

### `Math.abs()`

遍历过程中，当前位置的数字可能已经被之前的元素改成负数。因此读取数字时必须恢复它的绝对值：

```text
number = abs(nums[i])
```

否则负数无法正确映射到数组下标。

## 过程示例

使用较短的数组：

```text
nums = [2, 1, 2]
```

处理第一个数字 `2`：

```text
index = 2 - 1 = 1
nums[1] 当前是正数 1
将它改为 -1
```

数组变成：

```text
[2, -1, 2]
```

处理第二个位置时，当前值已经是 `-1`，所以先取绝对值：

```text
number = abs(-1) = 1
index = 1 - 1 = 0
```

将 `nums[0]` 标记为负数：

```text
[-2, -1, 2]
```

处理最后一个数字 `2`：

```text
number = abs(2) = 2
index = 1
nums[1] 已经是负数
```

说明数字 `2` 之前出现过，所以把 `2` 加入结果。

## 伪代码

```text
创建空结果数组

遍历 nums 中的每个位置 i：
    number = nums[i] 的绝对值
    index = number - 1

    如果 nums[index] 小于 0：
        number 是重复数字，加入结果
    否则：
        将 nums[index] 改成负数

返回结果数组
```

## JavaScript 代码

```js
/**
 * @param {number[]} nums
 * @return {number[]}
 */
var findDuplicates = function (nums) {
  const result = [];

  for (let i = 0; i < nums.length; i++) {
    const number = Math.abs(nums[i]);
    const index = number - 1;

    if (nums[index] < 0) {
      result.push(number);
    } else {
      nums[index] = -nums[index];
    }
  }

  return result;
};
```

## 复杂度分析

- 时间复杂度：`O(n)`。只遍历数组一次。
- 额外空间复杂度：`O(1)`。不计算返回结果，只使用少量变量并直接修改原数组。

## 这种方法的代价

原地正负标记会修改输入数组中的正负号。

如果调用方要求函数执行后保持原数组不变，可以在完成统计后再遍历一次，把所有元素恢复为绝对值：

```text
nums[i] = abs(nums[i])
```

但 LeetCode 本题允许修改输入数组，所以不需要恢复。

## 两种方法如何选择

| 方法 | 时间复杂度 | 额外空间 | 特点 |
| --- | --- | --- | --- |
| `Set` | `O(n)` | `O(n)` | 容易理解，适用于更一般的数值范围 |
| 原地正负标记 | `O(n)` | `O(1)` | 利用本题 `1 到 n` 的特殊条件 |

如果没有“数字都在 `1` 到 `n` 之间”的条件，原地正负标记就不能直接使用。

## 容易出错的地方

### 1. 忘记减一

数字 `number` 对应的下标是：

```text
number - 1
```

因为数组下标从 `0` 开始。

### 2. 没有对当前数字取绝对值

当前数组位置可能已经被改成负数，必须使用：

```text
Math.abs(nums[i])
```

### 3. 发现重复后再次改变符号

当 `nums[index]` 已经为负数时，只需要记录重复数字，不要再次取负，否则会把标记恢复成正数。

### 4. 使用数字本身作为下标

如果直接使用 `nums[number]`，数字 `n` 会访问下标 `n`，超出数组范围。必须映射为 `number - 1`。

### 5. 忽略方法会修改原数组

这种解法通过正负号保存状态，因此执行后 `nums` 的部分元素会变成负数。

### 6. 在不满足数值范围的题目中套用

原地标记依赖所有数字都能映射到合法数组下标。如果存在 `0`、负数或大于 `n` 的数字，就需要使用其他方法。
