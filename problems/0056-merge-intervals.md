# 56. 合并区间

- LeetCode：[56. 合并区间](https://leetcode.cn/problems/merge-intervals/)
- 难度：中等

## 先理解题意

每个区间使用两个数字表示：

```text
[开始位置, 结束位置]
```

如果两个区间存在重叠，就要把它们合并成一个更大的区间。

例如：

```text
[1, 3] 和 [2, 6]
```

因为第二个区间从 `2` 开始，而 `2` 还位于第一个区间 `[1, 3]` 内，所以它们重叠，合并后是：

```text
[1, 6]
```

对于：

```text
[[1, 3], [2, 6], [8, 10], [15, 18]]
```

最终结果是：

```text
[[1, 6], [8, 10], [15, 18]]
```

## 解题思路

先把所有区间按照开始位置从小到大排序。

排序后，区间会按照从左到右的顺序出现。此时处理一个新区间时，只需要和结果数组中的最后一个区间比较。

假设结果数组最后一个区间是：

```text
[lastStart, lastEnd]
```

当前区间是：

```text
[currentStart, currentEnd]
```

有两种情况。

### 情况一：存在重叠

```text
currentStart <= lastEnd
```

当前区间在上一个区间结束前已经开始，说明二者重叠。合并后的结束位置是：

```text
max(lastEnd, currentEnd)
```

### 情况二：不存在重叠

```text
currentStart > lastEnd
```

当前区间与上一个结果完全分开，需要把当前区间作为新的结果加入数组。

## 为什么必须先排序

如果区间顺序混乱，例如：

```text
[[8, 10], [1, 3], [2, 6]]
```

只比较相邻区间不能正确处理所有重叠关系。

按照起点排序后：

```text
[[1, 3], [2, 6], [8, 10]]
```

所有可能与当前合并结果重叠的区间都会连续出现，因此每次只需检查结果数组最后一个区间。

## 用到的数据结构及原因

### 二维数组 `intervals`

每个元素是一个长度为 `2` 的区间数组：

```text
[start, end]
```

先对 `intervals` 按照 `start` 排序，使区间从左到右排列。

### 结果数组 `result`

保存已经完成合并且彼此不重叠的区间。

处理新区间时，只需要查看：

```text
result[result.length - 1]
```

也就是结果中的最后一个区间。

## 用到的方法及原因

### 排序 `sort()`

按照每个区间的起点升序排列：

```js
intervals.sort((a, b) => a[0] - b[0]);
```

JavaScript 默认会把元素转换为字符串后排序，所以数字排序必须提供比较函数。

### 贪心合并

按起点排序后，每次尽可能把当前区间合并进最后一个结果区间。

如果无法合并，说明当前区间与之前所有合并结果都分离，可以安全地作为一个新区间加入结果。

### `Math.max()`

两个区间重叠时，合并区间的右边界应该取两者结束位置中的较大值：

```text
lastEnd = max(lastEnd, currentEnd)
```

不能直接使用 `currentEnd`，因为当前区间可能完全包含在已有区间中。

例如：

```text
[1, 10] 和 [2, 3]
```

合并结果仍然是 `[1, 10]`。

## 过程示例

输入：

```text
[[1, 3], [2, 6], [8, 10], [15, 18]]
```

先把第一个区间加入结果：

```text
result = [[1, 3]]
```

处理 `[2, 6]`：

```text
2 <= 3，存在重叠
合并为 [1, 6]
```

结果：

```text
result = [[1, 6]]
```

处理 `[8, 10]`：

```text
8 > 6，不重叠
```

结果：

```text
result = [[1, 6], [8, 10]]
```

处理 `[15, 18]`，同样不重叠，最终得到：

```text
[[1, 6], [8, 10], [15, 18]]
```

## 伪代码

```text
按照区间起点对 intervals 升序排序

创建 result
把第一个区间加入 result

从第二个区间开始遍历：
    current = 当前区间
    last = result 中最后一个区间

    如果 current 的起点 <= last 的终点：
        更新 last 的终点为两个终点中的较大值
    否则：
        把 current 加入 result

返回 result
```

## JavaScript 代码

```js
/**
 * @param {number[][]} intervals
 * @return {number[][]}
 */
var merge = function (intervals) {
  intervals.sort((a, b) => a[0] - b[0]);

  const result = [intervals[0]];

  for (let i = 1; i < intervals.length; i++) {
    const current = intervals[i];
    const last = result[result.length - 1];

    if (current[0] <= last[1]) {
      last[1] = Math.max(last[1], current[1]);
    } else {
      result.push(current);
    }
  }

  return result;
};
```

## 复杂度分析

设区间数量为 `n`：

- 时间复杂度：`O(n log n)`。主要开销是排序；排序后的遍历为 `O(n)`。
- 空间复杂度：`O(n)`。最坏情况下所有区间都不重叠，结果数组需要保存全部区间。排序本身的额外空间取决于 JavaScript 引擎实现。

## 为什么只和结果中的最后一个区间比较

区间已经按照起点升序排列，并且 `result` 中的区间已经完成合并。

如果当前区间不能与最后一个结果区间重叠：

```text
currentStart > lastEnd
```

那么它更不可能与结束位置更早的其他结果区间重叠。因此只需要比较最后一个区间。

## 容易出错的地方

### 1. 没有先排序

不排序就无法保证可能重叠的区间连续出现，也不能只比较结果中的最后一个区间。

### 2. 使用默认的 `sort()`

下面的写法会按照字符串规则排序：

```js
intervals.sort();
```

应该明确按照起点进行数字排序：

```js
intervals.sort((a, b) => a[0] - b[0]);
```

### 3. 重叠条件漏掉等号

区间端点相接也算重叠：

```text
[1, 4] 和 [4, 5] -> [1, 5]
```

所以条件是：

```text
current[0] <= last[1]
```

### 4. 直接把结束位置改成 `current[1]`

当前区间可能被已有区间完全包含。必须使用：

```text
max(last[1], current[1])
```

### 5. 每次都与原数组的前一个区间比较

连续多个区间可能合并成一个更大的区间，因此应该与 `result` 中最后一个已经合并的区间比较。

### 6. 忘记题目输入至少有一个区间

本题约束保证 `intervals` 非空，所以可以使用 `intervals[0]` 初始化结果。如果在其他场景中输入可能为空，需要先返回空数组。
