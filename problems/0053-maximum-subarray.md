# 53. 最大子数组和

- LeetCode：[53. 最大子数组和](https://leetcode.cn/problems/maximum-subarray/)
- 难度：中等

## 先理解题意

从数组中选择一段连续的元素，使这些元素的总和最大，并返回这个最大和。

例如：

```text
nums = [-2, 1, -3, 4, -1, 2, 1, -5, 4]
```

最大和的连续子数组是：

```text
[4, -1, 2, 1]
```

它的和是：

```text
4 + (-1) + 2 + 1 = 6
```

因此答案是 `6`。

注意是“子数组”，所以选择的元素必须连续。

## 解题思路

从左到右遍历数组。对于当前数字 `nums[i]`，以它结尾的最大子数组只有两种选择：

1. 不要前面的子数组，从当前数字重新开始。
2. 把当前数字接在前一个位置的最大子数组后面。

因此：

```text
以当前位置结尾的最大和
= max(当前数字, 前一个位置的最大和 + 当前数字)
```

如果前面累积的和是负数，它只会拖累当前数字，就应该丢弃前面的部分，从当前数字重新开始。

如果前面累积的和是正数，它能让当前结果更大，就应该继续连接。

## 动态规划状态

可以定义：

```text
dp[i] = 必须以 nums[i] 结尾的最大子数组和
```

状态转移是：

```text
dp[i] = max(nums[i], dp[i - 1] + nums[i])
```

最终答案不是一定等于 `dp` 的最后一个值，因为最大子数组可能在数组中间结束。因此需要取所有 `dp[i]` 中的最大值。

## 用到的数据结构及原因

### 两个数字变量

虽然可以使用 `dp` 数组保存每个位置的结果，但计算 `dp[i]` 时只需要 `dp[i - 1]`，不需要更早的状态。

因此可以把数组优化成两个变量：

- `currentMax`：以当前元素结尾的最大子数组和。
- `answer`：目前所有位置中出现过的最大子数组和。

选择两个变量的原因：

1. 当前状态只依赖前一个状态。
2. 不需要保存完整的 `dp` 数组。
3. 空间复杂度可以从 `O(n)` 降到 `O(1)`。

## 用到的方法及原因

### 动态规划

当前最优结果依赖前一个位置已经计算出的最优结果，因此适合使用动态规划。

### Kadane 算法

将动态规划状态压缩成常数空间的写法通常称为 Kadane 算法。它的核心就是不断决定：

```text
重新开始，还是继续累加？
```

### `Math.max()`

第一次用于决定当前子数组是重新开始还是继续连接：

```text
currentMax = max(nums[i], currentMax + nums[i])
```

第二次用于更新全局最大值：

```text
answer = max(answer, currentMax)
```

## 过程示例

以：

```text
[-2, 1, -3, 4, -1, 2, 1]
```

为例：

| 当前数字 | 以当前数字结尾的最大和 | 全局最大和 | 说明 |
| ---: | ---: | ---: | --- |
| `-2` | `-2` | `-2` | 第一个元素 |
| `1` | `1` | `1` | `-2 + 1` 不如从 `1` 重新开始 |
| `-3` | `-2` | `1` | 把 `-3` 接在 `1` 后面 |
| `4` | `4` | `4` | 前面的和为负数，从 `4` 重新开始 |
| `-1` | `3` | `4` | 继续连接得到 `4 + (-1)` |
| `2` | `5` | `5` | 继续连接 |
| `1` | `6` | `6` | 继续连接 |

最终答案是 `6`。

## 伪代码

```text
currentMax = nums[0]
answer = nums[0]

从下标 1 开始遍历：
    currentMax = 当前数字 与 currentMax + 当前数字 中的较大值
    answer = answer 与 currentMax 中的较大值

返回 answer
```

## JavaScript 代码

```js
/**
 * @param {number[]} nums
 * @return {number}
 */
var maxSubArray = function (nums) {
  let currentMax = nums[0];
  let answer = nums[0];

  for (let i = 1; i < nums.length; i++) {
    currentMax = Math.max(nums[i], currentMax + nums[i]);
    answer = Math.max(answer, currentMax);
  }

  return answer;
};
```

## 复杂度分析

设数组长度为 `n`：

- 时间复杂度：`O(n)`。只遍历数组一次。
- 空间复杂度：`O(1)`。只使用两个数字变量。

## 为什么不能把初始值设为 `0`

数组可能全部是负数，例如：

```text
[-3, -2, -5]
```

正确答案是：

```text
-2
```

如果把 `answer` 初始化为 `0`，最终可能错误返回 `0`，但数组中不存在和为 `0` 的非空子数组。

所以应该使用第一个元素初始化：

```text
currentMax = nums[0]
answer = nums[0]
```

并从下标 `1` 开始遍历。

## 容易出错的地方

### 1. 把子数组当成子序列

本题选择的元素必须连续，不能跳过中间元素后继续相加。

### 2. 只返回 `currentMax`

`currentMax` 只代表“必须以当前位置结尾”的最大和。最大子数组可能更早结束，所以还需要使用 `answer` 保存全局最大值。

### 3. 把初始值设成 `0`

这会导致全负数数组得到错误答案。应该使用 `nums[0]` 初始化。

### 4. 看到负数就一定重新开始

决定是否重新开始的依据不是当前数字是否为负，而是：

```text
nums[i] 和 currentMax + nums[i] 哪个更大
```

例如当前累计和是 `10`，当前数字是 `-2`，继续连接仍能得到 `8`，可能是最优选择的一部分。

### 5. 使用两层循环枚举所有子数组

枚举所有起点和终点需要 `O(n²)`。动态规划只需要一次遍历。
