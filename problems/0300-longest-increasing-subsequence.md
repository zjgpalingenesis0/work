# 300. 最长递增子序列

- LeetCode：[300. 最长递增子序列](https://leetcode.cn/problems/longest-increasing-subsequence/)
- 难度：中等

## 题目中的两个关键词

### 子序列

子序列不要求元素在原数组中连续，但必须保持原来的先后顺序。

例如数组：

```text
[10, 9, 2, 5, 3, 7, 101, 18]
```

`[2, 3, 7, 18]` 是子序列。虽然这些元素在原数组中不连续，但下标顺序没有改变。

### 严格递增

后一个元素必须大于前一个元素，不能相等。

```text
[2, 3, 7]     是严格递增
[2, 3, 3, 7]  不是严格递增
```

## 方法一：动态规划

### 解题思路

定义：

```text
dp[i] = 以 nums[i] 结尾的最长递增子序列长度
```

这里“以 `nums[i]` 结尾”非常重要，它表示当前子序列必须选择 `nums[i]`。

每个元素单独都能组成长度为 `1` 的递增子序列，因此所有 `dp[i]` 初始值都是 `1`。

计算 `dp[i]` 时，检查它前面的每个位置 `j`：

```text
j < i
```

如果：

```text
nums[j] < nums[i]
```

说明可以把 `nums[i]` 接到以 `nums[j]` 结尾的递增子序列后面：

```text
dp[i] = max(dp[i], dp[j] + 1)
```

最终答案不一定是 `dp` 的最后一个元素，因为最长递增子序列可能在数组中间结束，所以要取整个 `dp` 数组的最大值。

### 过程示例

以数组 `[1, 5, 2, 3]` 为例：

```text
nums[0] = 1
dp[0] = 1

nums[1] = 5
1 < 5，可以接在 1 后面
dp[1] = 2，对应 [1, 5]

nums[2] = 2
1 < 2，可以接在 1 后面
dp[2] = 2，对应 [1, 2]

nums[3] = 3
1 < 3，可以得到长度 2
2 < 3，可以得到长度 3
dp[3] = 3，对应 [1, 2, 3]
```

最终：

```text
dp = [1, 2, 2, 3]
```

答案是 `3`。

### 用到的数据结构及原因

#### 数组 `dp`

`dp[i]` 保存以 `nums[i]` 结尾的最长递增子序列长度。

使用数组的原因：

1. 每个状态和输入数组中的一个下标一一对应。
2. 计算后面的状态时，需要读取前面已经计算好的结果。
3. 可以直接通过下标进行 `O(1)` 访问。

### 用到的方法及原因

#### 动态规划

当前元素能否接在之前的递增子序列后面，取决于之前已经计算出的最优结果，符合动态规划的特点。

#### `new Array(length).fill(1)`

创建与输入数组等长的 `dp` 数组，并将每个状态初始化为 `1`。原因是任意一个元素自身都能构成长度为 `1` 的递增子序列。

#### `Math.max(a, b)`

用于比较当前结果和新找到的递增子序列长度，保留较大值。
最长递增子序列相当于第i个位置左侧小于它的值的最大个数
### 伪代码

```text
创建长度与 nums 相同的 dp 数组
将所有 dp[i] 初始化为 1
answer = 1

从左向右枚举位置 i：
    枚举 i 前面的每个位置 j：
        如果 nums[j] < nums[i]：
            dp[i] = dp[i] 和 dp[j] + 1 中的较大值

    使用 dp[i] 更新 answer

返回 answer
```

### JavaScript 代码

```js
/**
 * @param {number[]} nums
 * @return {number}
 */
var lengthOfLIS = function (nums) {
  const dp = new Array(nums.length).fill(1);
  let answer = 1;

  for (let i = 0; i < nums.length; i++) {
    for (let j = 0; j < i; j++) {
      if (nums[j] < nums[i]) {
        dp[i] = Math.max(dp[i], dp[j] + 1);
      }
    }

    answer = Math.max(answer, dp[i]);
  }

  return answer;
};
```

### 复杂度分析

- 时间复杂度：`O(n²)`。每个位置都要检查它前面的所有位置。
- 空间复杂度：`O(n)`。需要一个 `dp` 数组保存状态。

## 方法二：贪心 + 二分查找

### 解题思路

维护一个数组 `tails`：

```text
tails[i] = 长度为 i + 1 的递增子序列中，最小的结尾元素
```

这里 `tails` 不一定是真实的最长递增子序列，它记录的是不同长度递增子序列的最优结尾。

结尾越小，后面就越容易接上更大的元素。因此，处理每个新数字时：

- 如果它比 `tails` 中所有元素都大，就把它追加到末尾，说明最长长度增加了。
- 否则，找到 `tails` 中第一个大于或等于它的位置，并用它替换原值，使这个长度的子序列拥有更小的结尾。

`tails` 始终保持升序，所以可以使用二分查找定位替换位置。

### 过程示例

处理 `[10, 9, 2, 5, 3, 7]`：

```text
读取 10：tails = [10]
读取 9： tails = [9]
读取 2： tails = [2]
读取 5： tails = [2, 5]
读取 3： tails = [2, 3]
读取 7： tails = [2, 3, 7]
```

最终 `tails.length = 3`，所以最长递增子序列长度为 `3`。

把 `5` 替换成 `3` 不会让当前长度增加，但以 `3` 结尾比以 `5` 结尾更容易接上后续数字。

### 用到的数据结构及原因

#### 数组 `tails`

记录每种递增子序列长度能够取得的最小结尾。

选择数组的原因：

1. `tails` 始终保持升序，可以使用二分查找。
2. `tails.length` 就是目前找到的最长递增子序列长度。
3. 数组支持通过下标快速替换指定位置。

### 用到的方法及原因

#### 贪心

在递增子序列长度相同的情况下，总是保留更小的结尾元素，为后面的数字留下更多增长空间。

#### 二分查找

用于寻找 `tails` 中第一个大于或等于当前数字的位置，也就是“左边界”。

必须寻找“大于或等于”，而不是只寻找“大于”，因为题目要求严格递增。遇到相同元素时应该替换，而不是延长序列。

### 伪代码

```text
创建空数组 tails

遍历 nums 中的每个数字 num：
    使用二分查找，在 tails 中寻找第一个大于或等于 num 的位置

    如果这个位置等于 tails 的长度：
        把 num 添加到 tails 末尾
    否则：
        使用 num 替换该位置的元素

返回 tails 的长度
```

### JavaScript 代码

```js
/**
 * @param {number[]} nums
 * @return {number}
 */
var lengthOfLIS = function (nums) {
  const tails = [];

  for (const num of nums) {
    let left = 0;
    let right = tails.length;

    while (left < right) {
      const mid = left + Math.floor((right - left) / 2);

      if (tails[mid] < num) {
        left = mid + 1;
      } else {
        right = mid;
      }
    }

    tails[left] = num;
  }

  return tails.length;
};
```

### 复杂度分析

- 时间复杂度：`O(n log n)`。遍历所有元素，每个元素使用一次二分查找。
- 空间复杂度：`O(n)`。最坏情况下，`tails` 需要保存所有元素。

## 两种方法如何选择

| 方法 | 时间复杂度 | 特点 |
| --- | --- | --- |
| 动态规划 | `O(n²)` | 状态含义直观，适合先理解和推导 |
| 贪心 + 二分查找 | `O(n log n)` | 效率更高，但 `tails` 的含义更抽象 |

学习时建议先掌握动态规划，再理解为什么“相同长度的递增子序列，结尾越小越好”。

## 容易出错的地方

### 1. 把子序列当成子数组

子序列不要求连续，不能使用普通滑动窗口解决。

### 2. 动态规划状态定义不清楚

`dp[i]` 不是前 `i` 个元素中的最终答案，而是“必须以 `nums[i]` 结尾”的最长递增子序列长度。

### 3. 直接返回 `dp` 的最后一个值

最长递增子序列不一定以最后一个元素结尾，需要取整个 `dp` 数组中的最大值。

### 4. 忽略严格递增

动态规划的连接条件必须是：

```text
nums[j] < nums[i]
```

不能写成小于或等于。

### 5. 把 `tails` 当成真实答案序列

`tails` 的长度是正确答案，但其中保存的元素不一定构成原数组中的真实最长递增子序列。它的作用是记录每种长度下尽可能小的结尾。
