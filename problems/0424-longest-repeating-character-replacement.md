# 424. 替换后的最长重复字符

- LeetCode：[424. 替换后的最长重复字符](https://leetcode.cn/problems/longest-repeating-character-replacement/)
- 难度：中等

## 先理解题意

可以选择一个连续子串，最多修改其中 `k` 个字符，让这个子串中的所有字符都相同。题目要求这个子串的最大长度。

例如：

```text
s = "AABABBA"
k = 1
```

可以选择子串：

```text
"AABA"
```

其中 `A` 出现了三次，`B` 出现了一次。把 `B` 替换成 `A` 后得到：

```text
"AAAA"
```

只替换了一次，所以长度 `4` 是可行的。

## 解题思路

使用滑动窗口维护当前考虑的连续子串。

对于任意一个窗口，如果希望用最少的替换次数让所有字符相同，应该保留窗口中出现次数最多的字符，替换其他字符。

例如窗口：

```text
"AABA"
```

窗口长度是 `4`，其中出现次数最多的是 `A`，出现了 `3` 次。因此需要替换的字符数量是：

```text
4 - 3 = 1
```

一般公式是：

```text
需要替换的次数 = 窗口长度 - 窗口内最高字符频率
```

如果需要替换的次数小于或等于 `k`，当前窗口可行，可以继续扩大右边界。

如果需要替换的次数大于 `k`，当前窗口不可行，需要移动左边界缩小窗口。

## 用到的数据结构及原因

### 长度为 26 的频次数组 `frequency`

题目中的字符串只包含大写英文字母 `A` 到 `Z`，因此可以使用长度为 `26` 的数组记录每个字符在当前窗口中出现的次数。

```text
frequency[0] 记录 A 的次数
frequency[1] 记录 B 的次数
...
frequency[25] 记录 Z 的次数
```

选择数组的原因：

1. 字符范围固定，只有 26 种。
2. 根据字符下标查询和更新频率都是 `O(1)`。
3. 频次数组始终只有 26 个位置，可以快速寻找当前最高频率。

如果字符范围不是固定的大写字母，也可以改用 `Map`。

### 左右指针

- `left`：当前窗口的左边界。
- `right`：当前窗口的右边界。

窗口对应的连续子串范围是：

```text
[left, right]
```

窗口长度是：

```text
right - left + 1
```

## 用到的方法及原因

### 滑动窗口

右指针不断向右扩大窗口。如果当前窗口需要替换的字符超过 `k`，就移动左指针缩小窗口，直到窗口重新变得可行。

选择滑动窗口的原因：

1. 题目要求寻找连续子串。
2. 每个字符最多被右指针加入一次，被左指针移出一次。
3. 不需要枚举所有子串。

### `charCodeAt()`

JavaScript 可以通过字符编码把 `A` 到 `Z` 映射到数组下标 `0` 到 `25`：

```text
字符下标 = 当前字符编码 - A 的字符编码
```

也就是：

```js
s.charCodeAt(index) - 65
```

因为大写字母 `A` 的字符编码是 `65`：

```text
A -> 65 - 65 = 0
B -> 66 - 65 = 1
C -> 67 - 65 = 2
```

### `Math.max(...frequency)`

寻找当前窗口中出现次数最多的字符数量。

虽然每次需要检查频次数组，但数组长度固定为 `26`，所以这一步可以看作常数时间。

## 伪代码

```text
创建长度为 26 的频次数组，全部初始化为 0
left = 0
answer = 0

让 right 从左到右遍历字符串：
    将右边字符的出现次数加 1
    计算当前窗口内的最高字符频率

    当 窗口长度 - 最高字符频率 > k：
        将左边字符的出现次数减 1
        left 向右移动
        重新计算窗口内的最高字符频率

    使用当前窗口长度更新 answer

返回 answer
```

## JavaScript 代码

```js
/**
 * @param {string} s
 * @param {number} k
 * @return {number}
 */
var characterReplacement = function (s, k) {
  const frequency = new Array(26).fill(0);
  let left = 0;
  let answer = 0;

  for (let right = 0; right < s.length; right++) {
    const rightIndex = s.charCodeAt(right) - 65;
    frequency[rightIndex]++;

    let maxFrequency = Math.max(...frequency);

    while (right - left + 1 - maxFrequency > k) {
      const leftIndex = s.charCodeAt(left) - 65;
      frequency[leftIndex]--;
      left++;

      maxFrequency = Math.max(...frequency);
    }

    answer = Math.max(answer, right - left + 1);
  }

  return answer;
};
```

## 复杂度分析

设字符串长度为 `n`：

- 时间复杂度：`O(26 × n)`，因为每次计算最高频率需要检查 26 个位置。由于 26 是常数，通常写作 `O(n)`。
- 空间复杂度：`O(26)`，通常写作 `O(1)`。

## 为什么不是替换最少出现的字符

目标是让窗口内所有字符最终相同，因此应该选择窗口中已经出现次数最多的字符作为保留字符。

假设窗口是：

```text
"AAABC"
```

保留 `A` 只需要替换 `B` 和 `C`，共两次。如果保留 `B`，则需要替换另外四个字符，显然更差。

所以最少替换次数一定是：

```text
窗口长度 - 最高字符频率
```

## 容易出错的地方

### 1. 把子串当成子序列

本题选择的字符必须连续，所以适合使用滑动窗口。

### 2. 窗口长度忘记加一

窗口范围是闭区间 `[left, right]`，长度应该是：

```text
right - left + 1
```

### 3. 缩小窗口时忘记减少字符频率

左指针移动前，需要先把移出窗口的字符计数减一：

```text
frequency[leftCharacter]--
```

### 4. 判断条件写反

窗口不可行的条件是：

```text
窗口长度 - 最高字符频率 > k
```

只有超过 `k` 时才需要缩小窗口；等于 `k` 仍然是合法窗口。

### 5. 用 `if` 代替 `while`

移出一个字符后，窗口不一定立即恢复合法，所以应使用 `while` 持续缩小，直到替换次数不超过 `k`。

### 6. 使用普通对象时忘记初始化计数

本题使用固定长度数组并初始化为 `0`，可以避免 `undefined + 1` 得到 `NaN` 的问题。
